# 初中化学老师教酸碱盐的猎奇方式

酸碱盐是初中化学最难的部分。很多化学老师都会发明一些奇怪的记忆方式。

这里举一个例子。一个同学给我讲了他的补习班老师如何让他们记钡相关的难溶性盐。

> $\text{Ba}^{2+}$是$\text{SO}_4^{2-}$的唯一钟爱（$\text{BaSO}_4$），但$\text{SO}_4^{2-}$不是$\text{Ba}^{2+}$的唯一（还有$\text{CO}_3^{2-}$）。

自己说猎不猎奇。
