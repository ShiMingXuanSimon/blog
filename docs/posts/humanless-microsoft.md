# 微软不是人

> 微软在GitHub上开源发布了一款名为PowerToys的软件

PowerToys，顾名思义，就是一组（s）强大的（Power）的实用工具（Toy）。整个软件的业务逻辑是现代化的插件化结构，GUI则使用现代美观的UWP以与Windows11的窗口保持和谐。

PowerToys的功能弥补了Windows绝大多数饱受诟病的缺点，几乎把Windows变成了全世界最好用的操作系统。例如，**Always On Top**可以方便的将任意窗口置顶到**最顶端**；**查找我的鼠标**让你可以优雅的找到鼠标指针；**快速重音**让你可以方便的打出带变音符的字母；**命令面板**让你拥有类似于macOS上的Spotlight，优雅、高效、可扩展。
